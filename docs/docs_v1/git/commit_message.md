# 🔁 Summary

| Purpose  | Commit Message (`-m`)    | Tag Message                 |
| -------- | ------------------------ | --------------------------- |
| Length   | Shorter                  | Longer                      |
| Style    | Structured, code-focused | Narrative, user-facing      |
| Audience | Developers, tools        | Humans, release consumers   |
| Used in  | `git log`, CI, changelog | GitHub releases, `git show` |
| Format   | Conventional Commits     | Freeform (markdown often)   |
