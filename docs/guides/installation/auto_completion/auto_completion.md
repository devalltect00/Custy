## To install Auto-Completion
```
### Recommended
# This will install completion
# On Windows it will installed in C:\Users\{users}\.bash_completions\custy.sh
custy --install-completion

# OR

###
# This will install completion
# On Windows it will installed in C:\Users\{users}\.bash_completions\app.sh
python app --install-completion
```

## To uninstall Auto-Completion
```
custy --install-completion

python app --install-completion
```
