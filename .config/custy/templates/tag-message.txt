🩹 Custy v2.1.1 — Reliable Daily Development Workflows

Custy v2.1.1 is a focused patch release that corrects installed version output
and makes `custy run dev` a true daily commit-and-push workflow.

### Fixed

- `custy --help` and `custy --version` now report the exact stable package
  version without an unexpected `.post0` suffix when installed from v2.1.1.
- `custy run dev` opens only the commit-message file; it no longer opens an
  unused tag-message file.
- The Dev profile no longer prepares or applies release versions, generates
  release artifacts or changelogs, creates tags, or pushes tags.
- A successful Dev run stages the selected changes, creates the commit, and
  pushes branch `HEAD` to the resolved remotes.
- Release and Full profiles retain their existing version, changelog, tag, and
  publication behavior.

### Upgrade guidance

Install or upgrade to v2.1.1, then verify the active executable:

```bash
custy --version
custy --dry-run run dev
```

Dry-run remains non-mutating. A live Dev run still creates a commit and pushes
it, so review the resolved staging mode and remote destinations first.
