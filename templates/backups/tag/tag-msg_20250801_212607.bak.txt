📦 Release Candidate Release Custy 1.8.0rc1

Release candidate for **Custy 1.8.0** — Including finalized features and fixes. Awaiting final validation.

### ✨ Features
- **WorkflowManager**: validates branch ↔ tag consistency, enforces rules for `develop`, `release/*`, `main`, `hotfix/*`.
- **Branch Cleaner**: safely prune temporary branches (`feature/*`, `ci/*`, `sandbox/*`).
- **Branching Rules**: adopt 2 permanent branches (`main`, `develop`), with dual remote strategy (GitLab main, GitHub backup).

### 🛠 Improvements
- Updated `Makefile` with refined tasks.
- Expanded documentation for branching workflow and remote strategy.
