✅ Final Release Custy 1.8.0

**Custy 1.8.0** is now stable and production-ready. All feature and fixes from pre-releases (alpha, beta, rc) are included.

### ✨ Features
- **WorkflowManager**: validates branch ↔ tag consistency, enforces structured flow (`develop`, `release/*`, `main`, `hotfix/*`)
- **Branch Cleaner**: safely prunes `feature/*`, `ci/*`, and other temp branches
- **Dual Remote Strategy**: GitLab as main repo, GitHub as backup mirror
- **Version Helpers**: separate logic for PEP 440 and SemVer via `VersionHelperBase`

### ♻ Refactoring
- WorkflowManager now delegates version tasks via strategy pattern
- Simplified classification, tag suggestion, and transition logic
- Clean separation for future extensibility (e.g., CalVer)

### 🛠 Other improvements since 1.8.0rc2

- Updated `Makefile` to support `--sync-backup` when using `custy all`
- Added support for `release` commit type in version helpers
- Cleaned and structured `docs/TODO.md`
- Minor internal file updates for better maintainability
